# NUMBER CLASH
Real-time 2-player mental-math game. Node + Express + Socket.IO, server-authoritative.

    npm install
    npm start        # http://localhost:3000

Share the room code (or the invite link) with a friend on the same network / a deployed URL.
Server owns: room state, countdown, number generation limits, reveal, answer validation, server-timestamp winner, scores, rounds, rematch.
